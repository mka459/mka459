## How I Approach Problems

I believe strong machine learning work involves more than selecting an algorithm.

1. **Understand the problem.** Define the objective, constraints, and evaluation metric.
2. **Investigate the data.** Identify patterns, missing values, leakage risks, and potential sources of bias.
3. **Build a reliable baseline.** Establish a measurable reference before introducing complexity.
4. **Experiment with purpose.** Test hypotheses that could materially improve performance.
5. **Evaluate rigorously.** Use appropriate validation strategies and analyze errors beyond a single aggregate metric.
6. **Deliver something useful.** Translate model outputs into interpretable insights or practical applications.

My approach is iterative: investigate, experiment, measure, and keep what works.
